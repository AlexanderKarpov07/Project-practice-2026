# Полезные ресурсы проекта Eltech

В этом разделе собраны ссылки на организацию-партнера, документацию, курсы и материалы, которые полезны для разработки мобильного приложения Eltech.

## Организация-партнер

* [Московский Политех](https://mospolytech.ru/) - база обучения и основная площадка реализации проекта.
* [Факультет информационных технологий Московского Политеха](https://mospolytech.ru/obuchenie/fakultety-i-instituty/fakultet-it/) - образовательная среда, связанная с разработкой цифровых решений.

## Kotlin Multiplatform и Compose Multiplatform

* [Официальная документация Kotlin Multiplatform](https://kotlinlang.org/docs/multiplatform.html) - руководство по созданию мультиплатформенных приложений.
* [JetBrains Kotlin Multiplatform](https://www.jetbrains.com/kotlin-multiplatform/) - обзор технологии и сценариев применения для iOS и Android.
* [Compose Multiplatform](https://www.jetbrains.com/lp/compose-multiplatform/) - декларативный UI для Android, iOS, Desktop и Web.
* [KMP Awesome List](https://github.com/terrakok/kmp-awesome) - подборка библиотек, инструментов и примеров для KMP.

## Android-разработка

* [Android Developers](https://developer.android.com/) - официальная документация для Android-разработчиков.
* [Material Design 3](https://m3.material.io/) - гайдлайны по дизайну мобильных интерфейсов.
* [Modern Android Development](https://developer.android.com/modern-android-development) - современные практики разработки Android-приложений.

## Курсы и статьи

* [Metaclass: Android-разработчик с нуля](https://metaclass.ru/) - курс по современной мобильной разработке.
* [Medium: Kotlin Multiplatform](https://medium.com/tag/kotlin-multiplatform) - статьи и разборы архитектурных решений.
* [Habr: мобильная разработка](https://habr.com/ru/hub/mobile_dev/) - русскоязычные материалы о мобильных приложениях, сетевых слоях, кэше и SDK.
