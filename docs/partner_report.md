# Отчёт о взаимодействии с организацией-партнёром проекта Eltech

## 1. Общая информация

**Проект:** Eltech

**Группа:** 251-371  
**Организация-партнёр:** Московский Политех  
**Связанные сервисы:** личный кабинет, расписание, LMS/Moodle, учебные данные, сервисы физической культуры

Проект Eltech связан с цифровой средой Московского Политеха. В качестве организации-партнёра рассматривается университет, так как именно его сервисы и пользовательские сценарии лежат в основе разрабатываемого мобильного приложения.

## 2. Формат взаимодействия

В рамках практики взаимодействие с организацией-партнёром рассматривалось через анализ потребностей пользователей и изучение цифровой инфраструктуры университета. Основное внимание было уделено тому, какие задачи студенты решают через личный кабинет и какие сценарии требуют более удобного мобильного интерфейса.

Формы взаимодействия и анализа:

* изучение открытых материалов Московского Политеха;
* анализ пользовательских сценариев студентов;
* изучение структуры цифровых сервисов университета;
* сопоставление требований проекта Eltech с потребностями студентов;
* оформление результатов в документации и на сайте проекта.

## 3. Полученные знания и навыки

В ходе работы над проектом были получены знания о том, как устроены пользовательские сценарии внутри университетской цифровой среды. Особенно важным оказалось понимание того, что мобильное приложение должно быть не просто копией веб-версии личного кабинета, а отдельным удобным инструментом для быстрых действий.

### 3.1. Понимание потребностей студентов

Студенты регулярно обращаются к расписанию, учебным материалам, данным об успеваемости и отдельным сервисам личного кабинета. На смартфоне такие действия должны выполняться быстро и без лишних переходов.

Ключевые потребности:

* быстрый просмотр расписания;
* доступ к LMS/Moodle;
* получение учебной информации в понятном формате;
* отслеживание индивидуального прогресса;
* работа приложения без визуальной перегрузки.

### 3.2. Понимание требований к мобильному интерфейсу

Для проекта Eltech важно учитывать, что мобильный интерфейс используется в коротких повседневных сценариях: перед парой, в дороге, во время проверки расписания или учебных заданий. Поэтому интерфейс должен быть адаптивным, лаконичным и устойчивым к ошибкам пользователя.

Основные выводы:

* один экран должен решать одну понятную задачу;
* важные данные должны быть видны без долгого поиска;
* интерфейс должен соответствовать визуальному стилю Московского Политеха;
* приложение должно учитывать разные типы учебных сервисов.

## 4. Связь взаимодействия с моим вкладом

Мой вклад в проект связан с направлением **«Экран физической культуры»**. Этот экран помогает студенту отслеживать прогресс по физкультуре: накопленные баллы, посещения занятий и связанные данные из личного кабинета.

| Полученное знание | Как применено в проекте |
| --- | --- |
| Студенту важно быстро видеть текущий прогресс | Экран физкультуры должен показывать баллы и посещения без лишних переходов |
| Данные должны быть понятны без пояснений преподавателя | В интерфейсе важно использовать простые подписи и наглядное отображение прогресса |
| Мобильный сценарий должен быть коротким | Экран должен открываться быстро и сразу показывать главные показатели |
| Информация берётся из цифровой среды университета | Необходима связь с личным кабинетом и общей архитектурой SDK_Eltech |

## 5. Результаты взаимодействия

По итогам анализа были уточнены требования к проекту Eltech и к отдельному экрану физической культуры:

1. Экран должен быть ориентирован на быстрый просмотр прогресса.
2. Данные должны отображаться в понятном и компактном виде.
3. Интерфейс должен быть связан с общей архитектурой приложения.
4. Для дальнейшего развития важно обеспечить корректную работу с данными личного кабинета.

## 6. Планы по доработке

В дальнейшем для экрана физической культуры можно развивать следующие функции:

* отображение истории посещений;
* детализация начисленных баллов;
* уведомления о необходимости закрыть недостающие занятия;
* улучшение визуального отображения прогресса;
* синхронизация с общим профилем студента в приложении.

## 7. Вывод

Взаимодействие с организацией-партнёром в рамках проекта Eltech позволило лучше понять, какие задачи решает цифровая среда Московского Политеха и какие требования предъявляются к мобильному приложению. Для моего направления это особенно важно, так как экран физической культуры должен быть полезным, понятным и связанным с реальными данными студента.
