# Отчёт по онлайн-курсам LLM

## Цель изучения

В рамках проектной практики были изучены материалы по большим языковым моделям (LLM), промпт-инжинирингу, этическим аспектам применения искусственного интеллекта и использованию LLM в разработке и документировании.

Полученные знания применялись при подготовке документации проекта Eltech, структурировании материалов сайта и формулировании описаний выполненных этапов практики.

## Курс 1. Введение в LLM и архитектуру Transformer

**Источник:** Hugging Face NLP Course  
**Ссылка:** <https://huggingface.co/learn/nlp-course>

В рамках курса были изучены базовые принципы работы больших языковых моделей:

* архитектура Transformer;
* механизм внимания;
* токенизация текста;
* общий жизненный цикл модели;
* задачи обработки естественного языка.

Полученные знания помогли лучше понимать, как LLM анализируют текст, генерируют ответы и почему для качественного результата важна структура запроса.

## Курс 2. Промпт-инжиниринг

**Источник:** материалы по работе с GigaChat и практики составления запросов  
**Ссылка:** <https://developers.sber.ru/docs/ru/gigachat/overview>

В рамках изучения промпт-инжиниринга были рассмотрены:

* постановка роли и контекста для модели;
* уточнение формата ответа;
* декомпозиция сложной задачи на шаги;
* проверка результата и уточнение запроса;
* использование LLM для редактирования текста и генерации структуры документа.

Эти навыки применялись при подготовке Markdown-документации и итогового отчёта по проекту.

## Курс 3. Этические аспекты использования ИИ

**Источник:** статьи и материалы Habr по теме искусственного интеллекта  
**Ссылка:** <https://habr.com/ru/hubs/artificial_intelligence/articles/>

В ходе изучения были рассмотрены вопросы ответственного применения ИИ:

* риски недостоверных ответов;
* необходимость проверки фактов;
* защита персональных данных;
* прозрачность использования ИИ-инструментов;
* ограничения автоматической генерации текстов и кода.

Для практики это важно, потому что LLM использовалась только как вспомогательный инструмент, а итоговые материалы проверялись и адаптировались под реальный проект Eltech.

## Курс 4. Применение LLM в разработке и документировании

**Источник:** материалы Hexlet и практические подходы к использованию ИИ в разработке  
**Ссылка:** <https://ru.hexlet.io/>

В рамках курса были изучены способы применения LLM в рабочих задачах разработчика:

* генерация структуры документации;
* объяснение фрагментов кода;
* подготовка README и технических описаний;
* помощь в создании HTML/CSS-страниц;
* проверка полноты требований по заданию.

В проектной практике эти навыки использовались при оформлении `docs/`, разработке сайта в `site/` и подготовке итогового отчёта.

## Пример применения LLM в практике

LLM была использована для помощи в структурировании материалов проекта Eltech:

1. На основе исходной информации были выделены разделы «О проекте», «Участники», «Журнал» и «Ресурсы».
2. Для сайта была подготовлена структура страниц и навигации.
3. Для отчёта были сформированы разделы, соответствующие требованиям практики.
4. Итоговые тексты были проверены на полноту, связность и соответствие теме проекта.

## Вывод

Изучение LLM позволило эффективнее подготовить проектную документацию и сайт. При этом ключевым условием осталось самостоятельное редактирование и проверка результата, так как материалы практики должны соответствовать реальному проекту и требованиям задания.
