# Журнал прогресса проекта Eltech

Этот журнал фиксирует основные этапы работы над мобильным приложением Eltech. Записи отражают разработку SDK, отдельных экранов, доменной архитектуры и интеграции с учебными сервисами.

## 01.03.2026 - старт разработки SDK

**Участники:** Воронин Даниил, Смирнов Ярослав

Начата разработка основной библиотеки **SDK_Eltech** для взаимодействия с внутренними API университета. Команда подготовила техническое описание базовых методов SDK, описала структуры запросов и ответов, чтобы дальнейшая работа над модулями приложения была согласованной.

## 15.03.2026 - экран физической культуры

**Участник:** Карпов Александр

Реализован специализированный экран для отслеживания прогресса по физической культуре. В приложение добавлена логика отображения накопленных баллов и посещений занятий на основе данных из личного кабинета.

## 26.03.2026 - интеграция с LMS

**Участник:** Клепиков Станислав

Реализован базовый функционал взаимодействия с системой управления обучением **LMS/Moodle**. Настроены механизмы парсинга учебных материалов и интеграция пользовательских сессий для удобного перехода из приложения к заданиям.

## 15.04.2026 - доменный слой

**Участник:** Станкевич Михаил

Завершена работа над архитектурой **Domain Layer**. Описаны бизнес-сущности и сценарии использования, что позволило отделить основную логику приложения от инфраструктурных деталей.

## 22.04.2026 - экран расписания

**Участник:** Фролков Даниил

Реализована базовая верстка основного экрана расписания. Созданы адаптивные UI-компоненты для карточек занятий, добавлена логика отображения текущего дня и переключения между датами.
