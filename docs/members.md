# Участники проекта

В проекте Eltech команда распределяет задачи по направлениям: SDK, доменная логика, кэширование, интерфейс, экраны приложения и документация.

## Основные направления работы

* **SDK_Eltech** - общая библиотека для взаимодействия с сервисами университета.
* **Domain** - бизнес-сущности и сценарии использования.
* **Cache** - локальное хранение данных и ускорение повторных запросов.
* **UI** - экраны и визуальные компоненты приложения.
* **Документация** - описание архитектуры, методов SDK и прогресса команды.

> Личный вклад Карпова Александра связан с направлением «Экран физической культуры».

## Распределение ролей

* **Руководство и архитектура:** постановка технических решений, контроль качества и планирование релизов.
* **SDK и интеграции:** разработка общей библиотеки для связи с внутренними сервисами университета.
* **Domain:** описание бизнес-сущностей и сценариев использования.
* **Cache:** организация локального хранения данных и оптимизация повторных запросов.
* **UI:** создание экранов, компонентов и визуальной логики приложения.
* **Документация:** описание технических решений, методов SDK и прогресса команды.
