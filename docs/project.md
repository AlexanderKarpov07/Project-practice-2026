# Проект Eltech

## Краткое описание

**Eltech** - студенческий проект по разработке кроссплатформенного мобильного приложения для Московского Политеха. Приложение должно сделать цифровые сервисы университета удобными для использования со смартфона: расписание, учебные материалы, элементы личного кабинета и связанные сервисы.

Проект развивается как открытое решение и ориентирован на дальнейший запуск для платформ Android и iOS.

## Актуальность

Сейчас значительная часть университетских сервисов доступна через веб-интерфейс личного кабинета. На смартфонах такой формат не всегда удобен: пользователю приходится открывать браузер, масштабировать страницы и переходить между разными разделами. Полноценное мобильное приложение помогает решить эту проблему и повышает качество взаимодействия студентов с цифровой средой университета.

Актуальность проекта связана с несколькими факторами:

* студенты регулярно используют расписание, LMS/Moodle и личный кабинет;
* мобильный сценарий является основным для быстрых повседневных действий;
* единое приложение снижает количество лишних переходов между сервисами;
* кроссплатформенная архитектура упрощает развитие продукта сразу для Android и iOS.

## Цель

Создать удобное кроссплатформенное мобильное приложение для доступа к ключевой информации и цифровым сервисам Московского Политеха со смартфонов.

## Задачи

* Перенести основной функционал веб-версии личного кабинета в формат мобильного приложения.
* Разработать общую библиотеку и SDK на базе Kotlin Multiplatform.
* Реализовать интерфейс, соответствующий визуальному стилю Московского Политеха.
* Поддержать работу с расписанием, LMS/Moodle, авторизацией и пользовательскими данными.
* Подготовить архитектуру, которую можно расширять после первых релизов.

## Технологическая основа

В основе проекта используется **Kotlin Multiplatform (KMP)**. Такой подход позволяет переиспользовать бизнес-логику между платформами и поддерживать единую кодовую базу для важных частей приложения.

Ключевые направления разработки:

| Направление | Содержание |
| --- | --- |
| SDK_Eltech | Общая библиотека для работы с внутренними API |
| Domain Layer | Бизнес-сущности и сценарии использования |
| Cache | Локальное хранение и ускорение доступа к данным |
| UI | Экраны приложения и компоненты интерфейса |
| LMS | Интеграция с системой управления обучением |

## Ожидаемые результаты

* Стабильная версия мобильного приложения для Android.
* Подготовка архитектуры для дальнейшего запуска на iOS.
* Работающий SDK, который можно использовать в разных частях продукта.
* Возможность получения официального статуса клиента Московского Политеха.
