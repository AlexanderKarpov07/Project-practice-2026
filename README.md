## Проектная деятельность

Практика связана с проектом **Eltech** - кроссплатформенным мобильным приложением для Московского Политеха. Проект направлен на создание удобного мобильного доступа к расписанию, LMS/Moodle и другим цифровым сервисам университета.

## Часть по выбору

Выбран вариант **2.2. Практическая реализация технологии «с нуля»**.

В рамках вариативной части реализован простой HTTP-сервер на Python без веб-фреймворков. Исходный код находится в папке `src/`, техническое руководство - в `docs/variant_guide.md`, описание на сайте - в `site/practical.html`.
