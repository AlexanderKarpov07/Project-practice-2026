# Исходный код вариативной части 2.2

В этой папке находится практическая реализация технологии «с нуля» для части 2.2 проектной практики.

## Выбранная технология

**HTTP-сервер на Python без веб-фреймворков.**

Сервер реализован на стандартной библиотеке Python:

* `socket` - приём TCP-соединений;
* `json` - формирование JSON-ответа;
* `pathlib` - чтение локального SVG-файла;
* ручная сборка HTTP-заголовков.

## Файлы

| Файл | Назначение |
| --- | --- |
| `handle_request.py` | Исходный код HTTP-сервера |

## Запуск

Из корня репозитория:

```bash
python src/handle_request.py
```

После запуска доступны маршруты:

| Маршрут | Описание |
| --- | --- |
| `http://localhost:8080/` | HTML-страница о проекте Eltech |
| `http://localhost:8080/api/status` | JSON со статусом проекта |
| `http://localhost:8080/architecture.svg` | SVG-схема архитектуры |

## Связь с проектом Eltech

Сервер реализует самостоятельную технологию из задания, но тематически связан с основным проектом: он отдаёт демонстрационную страницу о Eltech и JSON-данные, которые имитируют простой backend-эндпоинт для статуса проекта.
