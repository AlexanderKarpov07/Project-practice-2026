# Исходные файлы вариативной части

В этой папке размещены Kotlin-файлы, связанные с вкладом в проект **Eltech**.

## Состав

| Файл | Назначение |
| --- | --- |
| `PhysicalScreen.kt` | Экран физической культуры: карточка студента, посещения, вкладки «Посещения», «Нормативы», «Доп. баллы», переход к журналу группы |
| `GroupJournalScreen.kt` | Экран журнала группы: список студентов, посещения, баллы, LMS и группа здоровья |
| `HomeScreen.kt` | Главный экран сервисов с навигацией к экрану физической культуры |

## Связь с проектом

Файлы относятся к модулю интерфейса приложения Eltech на Kotlin Multiplatform / Compose Multiplatform. Они демонстрируют практическую реализацию части пользовательского сценария: переход из раздела сервисов к экрану физической культуры и просмотру журнала группы.

## Личный вклад

В рамках практики эти файлы используются как подтверждение вариативной части: реализации функционального фрагмента приложения, связанного с экраном физической культуры.

Основные реализованные элементы:

* экран физической культуры;
* отображение данных студента;
* список посещений;
* вкладки для разных типов данных;
* карточка перехода в журнал группы;
* экран журнала группы;
* интеграция перехода из `HomeScreen`.

## Примечание

Файлы являются частью исходного проекта Eltech и предназначены для демонстрации выполненной практической работы. Для полноценной сборки требуется окружение исходного Kotlin Multiplatform-проекта.
