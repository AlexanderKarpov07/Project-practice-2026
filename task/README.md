# Задание на проектную практику

## Обязательная часть

### 1. Настройка Git и репозитория

Необходимо настроить систему контроля версий, создать репозиторий, изучить базовые команды Git и регулярно фиксировать изменения осмысленными коммитами.

### 2. Изучение Markdown и создание документации проекта

В папке `docs/` требуется подготовить Markdown-документацию проекта:

* `docs/project.md` - описание проекта, цели, задачи и актуальность;
* `docs/members.md` - участники команды и личный вклад;
* `docs/journal.md` - журнал прогресса с датами;
* `docs/resources.md` - полезные ссылки и материалы.

### 3. Создание веб-сайта

В папке `site/` требуется разработать статический сайт по проекту. Обязательные страницы и разделы:

* главная страница;
* о проекте;
* участники;
* журнал;
* ресурсы.

Сайт должен открываться в браузере без дополнительных серверных настроек.

## Проект

Основной проект по дисциплине «Проектная деятельность» - **Eltech**, мобильное приложение для сервисов Московского Политеха.
