Часть 2.2

HTTP-сервер с нуля

Практическая реализация технологии без фреймворков: Python-сервер на сокетах, который отдаёт страницу проекта Eltech, JSON-эндпоинт и локальные SVG-материалы.

Назначение

Что реализовано

Для вариативной части выбран вариант 2.2: практическая реализация технологии «с нуля». В качестве технологии реализован минимальный HTTP-сервер на Python с использованием стандартной библиотеки socket.

Сервер связан с основным проектом тематически: он показывает краткую страницу о Eltech и предоставляет JSON-статус проекта, который можно использовать как демонстрационный backend-эндпоинт.

Файлы

  • src/handle_request.py - исходный код HTTP-сервера.
  • src/README.md - описание запуска и структуры.
  • docs/variant_guide.md - техническое руководство.

Архитектура

Схема работы

Браузер
  └── HTTP-запрос
        └── socket-сервер Python
              ├── GET /              -> HTML-страница
              ├── GET /api/status    -> JSON-статус проекта
              ├── GET /architecture.svg -> SVG-схема
              └── другой путь        -> 404 Not Found

Маршрутизация

Ручная обработка запросов

Сервер самостоятельно читает первую строку HTTP-запроса, извлекает путь и выбирает ответ. Это демонстрирует базовые принципы работы HTTP без Flask, Django, FastAPI и других фреймворков.

Маршруты

  • / - HTML-страница проекта.
  • /api/status - JSON с данными Eltech.
  • /architecture.svg - схема архитектуры.

Фрагмент кода

Запуск сервера

server = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
server.bind(("localhost", 8080))
server.listen(5)

while True:
    client, address = server.accept()
    request = client.recv(4096).decode("utf-8", errors="ignore")
    response = handle_request(request)
    client.sendall(response)
    client.close()

Модификация

Связь с проектом Eltech

Сверх базовой реализации сервер содержит тематическую HTML-страницу, JSON-эндпоинт с данными проекта и отдачу локальной SVG-схемы. Это делает техническую часть связанной с проектной деятельностью, но сама технология реализована отдельно и с нуля.
