Часть 2.2

Экран физической культуры

Практическая реализация фрагмента мобильного приложения Eltech на Kotlin/Compose: экран физкультуры, журнал группы и переход из раздела сервисов.

Назначение

Что реализовано

Вариативная часть связана с личным вкладом в проект Eltech. Реализован интерфейсный фрагмент, который помогает студенту просматривать информацию по физической культуре: посещения, баллы, LMS и журнал группы.

Решение отличается от примера с HTTP-сервером: здесь выполнена работа с Kotlin Multiplatform и Compose Multiplatform, то есть с технологией, близкой к основному проекту.

Файлы в src

  • PhysicalScreen.kt - основной экран физической культуры.
  • GroupJournalScreen.kt - экран журнала группы.
  • HomeScreen.kt - переход к экрану из раздела сервисов.

Архитектура

Связь экранов

PhysicalScreen.kt

Основной экран

Экран содержит карточку студента, данные по курсу и группе здоровья, блоки «ЛМС» и «Всего», список посещений и вкладки для переключения между разделами.

Ключевые элементы

  • состояние выбранной вкладки;
  • открытие журнала группы;
  • карточки посещений;
  • placeholder для разделов без данных.

Фрагмент кода

Переход к экрану

serviceItem(
    "Физическая культура",
    "Посещаемость и Оценка",
    Color(0xFFF5C6D6),
    Icons.Default.FitnessCenter
) {
    openPhys = true
}

Результат

Практическая ценность

Реализация показывает, как отдельный сервис университета может быть встроен в мобильное приложение. Экран физической культуры является частью повседневного сценария студента и дополняет общую цифровую среду Eltech.
